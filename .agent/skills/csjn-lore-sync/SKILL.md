# 《长生纪年》长篇一致性与状态账本技能

> 目标：在十四世多世界长篇连载中，确保人物性格、光影板块物理规则、身法阶段、燃寿代价与草蛇灰线零穿帮。

## 一、写前上下文加载（强制）

动笔写任何章节前，必须按需读取以下本地文件（严禁凭记忆瞎编设定）：
1. `writing/00-设定圣经-总纲.md`：核对主角反龙傲天边界、万古黑砖状态、当前光影板块规则。
2. `writing/01-十四世分卷大纲.md`：定位当前所写卷次的节拍（起/承/转/合/引）、化名、同行者与退场方式。
3. `writing/02-人物与关系图谱.md`：核对当前出场人物的性格、口头禅、信条与关系。
4. `writing/state/current_state.md`：确认上一章结尾时间点、主角寿元/伤痕状态与结尾钩子。
5. `writing/state/pending_hooks.md`：检查本卷有哪些必须埋下或回收的伏笔。

## 二、一致性审计清单（写中/写后必查）

1. **反龙傲天红线**：主角是否违规使用了超越当前阶段的武力碾压？遇到强敌是否优先用智谋、隐忍或“缩地身法”脱身？
2. **身法阶段锁**：前两卷（青溪县城、大景皇朝）主角**尚未习得**“红尘缩地步”，不可提前使用缩地神技；第三、四卷才习得初阶“顺风追星步”。
3. **光影板块物理约束**：
   - `常昼常夜板块`：注意年龄伪装、户籍与日常烟火。
   - `极昼炽域板块`：无黑夜遮掩，强光下伤疤、影子、延迟足迹极易暴露。
   - `极夜寒渊板块`：依赖微光秩序，高速机动会急剧透支体温与阳气，事后需烤火/喝热茶缓神。
   - `晨昏交界板块`：三十里狭缝，光暗规则对撞。
4. **万古黑砖（手机）状态**：现代以前始终处于**彻底断网黑屏**状态（仅可作镇纸、冷光微闪或燃寿留影媒介），严禁提前出现现代联网或充电亮屏剧情。
5. **人物知识边界（POV 隔离）**：配角不能知道他们视角之外的主角秘密。
6. **入世衰老与归真复青铁律**：主角外貌在每一世随当前世年龄同步自然变老（起皱、白发、老态），以合常昼常夜板块旁人观感；直至本世羁绊圆满退场、长生录结算完成后，方恢复二十五岁青年真容。朝夕相处的枕边人可隐约察觉其筋骨心跳之异，却不可轻易对旁人点破。

## 三、写后事务更新（强制）

每章定稿后，必须同步更新：
1. `writing/state/current_state.md`：更新当前卷章、主角化名与年龄、时间坐标、新增伤痕/燃寿代价、本章结尾钩子。
2. `writing/state/pending_hooks.md`：新增本章埋下的伏笔（标注 `[ ]`），若回收了旧伏笔则勾选为 `[x]` 并注明回收章节。
3. 若本轮创作对设定做了重大微调，提醒作者同步更新 `src/data/novelData.ts` 并重跑 `bun run scripts/sync-writing-bible.ts`。

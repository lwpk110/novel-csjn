# 《长生纪年》7 道去 AI 味审稿技能

> 核心信念：去 AI 味不是把文章改碎，而是把过度圆滑、工整、像剧情说明书的“机器腔”，拉回有人、有场、有冲突、有余波、带烟火气的人话。

## 四大改写铁律（先于一切规则）

1. **最小改动**：一处命中只改必需部分；没有问题的句子原样保留。
2. **信息守恒**：剧情、事实、伏笔、人物态度、燃寿/伤痕证据一概不删不改，只改“怎么说”。
3. **不制造参差**：不要为了“像人写”而刻意把句子拆成忽长忽短的电报体（连续 ≤8 字短句连排同样是病）。
4. **智能替换，严禁机械删除**：删除词句后必须默读检查语义是否断裂；对话引号内若符合人物惊讶/口语，可合理保留。

## 量化检测前置（推荐每次整章审稿前运行）

```bash
python3 scripts/de-ai/detect.py writing/chapters/<章节文件>.md
```
重点关注输出的 **A 级（翻案腔、起手式、当…时从句、前置话题壳、句首连接词）** 与 **B 级（顿号并列≥3、过长前置定语）** 命中项。

## 7 道审查闸门（7-Gate）

### Gate 1：机器高频词智能替换
检索并按语境替换以下高频 AI 词（对话内符合口语可留）：
- `仿佛 / 宛如` → 删去或改为更具体的比喻/动作（如 `像是`、`好比`），严禁删成病句。
- `竟然 / 居然` → 优先删去，通过前文铺垫反差体现惊讶；确需保留仅限对话。
- `不禁` → 删除，直接写具体动作（`不禁笑了` → `笑了` / `嘴角动了动`）。
- `深邃` → 换为具体质感（`漆黑`、`幽暗`、`沉`）。
- `瞳孔收缩 / 嘴角上扬 / 眼底闪过一丝` → 替换为真实可感的小动作（`眨了眨眼`、`后退半步`、`攥紧袖口`、`低头喝茶`）。
- `命运 / 宿命 / 羁绊`（非系统术语时）→ 改为具体际遇或人际称谓。

### Gate 2：翻案腔与毒句式（520万字语料最高频 AI 信号）
以下句式实测 AI 出现率是人类的 3.4 倍，除非存在**真实逻辑反差**，否则一律改写为正面直陈：
- `不是……而是……` / `并非……而是……` / `与其说……不如说……`
- `看似……实则……` / `表面……实际……` / `没有 X，只有 Y`
- `声音不大，却带着不容置疑的……` / `这一刻，……`
- 改法示例：`他不是不怕死，而是不想死得太难看` → `他怕死，更怕死得难看`。

### Gate 3：心理告知与“梗概感/汇报腔”
- **去梗概感**（源自 `fiction-humanizer-zh`）：少用 `她意识到` / `他明白了` / `这让他感到` 替代真实反应；每个核心转折要按「铺垫 → 尝试与阻碍 → 选择代价 → 后续余波」演出来，不要把事件写成结果摘要。
- 删除“重复告知”（前文动作已体现愤怒，后文又写“他心中涌起一股怒火”）。
- 禁止用“手抖、握拳、指节发白”批量替代所有心理描写。

### Gate 4：节奏均匀与排比三连
- 打散机械排比三连（`他看到了……他听到了……他感受到了……`）。
- 避免连续 4 段以上字数高度齐整的“豆腐块”。

### Gate 5：对话腔调去端着
- 删掉多余修饰标签（`沉声道`、`淡淡地说`、`戏谑地挑眉` → 优先用 `说` 或直接靠动作承接对话）。
- 对白不要互相解释读者已知的信息；禁止角色在生死关头或日常闲聊中说“书面语长难句”。

### Gate 6：结尾升华与强行留白
- **严禁每章/每段结尾来一句哲理总结或感慨**（如“长生路上，或许这就是代价吧”）。
- 让最后一个具体动作、物件特写或悬念直接收尾。

### Gate 7：解释腔与上帝视角
- 清理 `她不知道的是……`、`之所以……是因为……`、`这意味着……` 等旁白剧透腔，贴近主角当下限知视角。

## 输出格式
1. 先给简短《去味自检清单》（列出 `detect.py` 命中项 + 命中的 Gate 编号与修改处）。
2. 再输出净化后的完整正文（正文内不夹杂任何批注）。
